# 갤러리워크 - 달빛 제단

## 정자 장면 생성 - 권장

1. Unity Hub에서 `CG_2491051` 프로젝트를 연다.
2. 스크립트 컴파일이 끝날 때까지 기다린다.
3. Unity 상단 메뉴에서 `CG > Mid > Build Pavilion Gallery Scene`을 누른다.
4. 생성된 `Assets/Mid/Mid_Gallery_Pavilion.unity` 장면을 저장하고 실행한다.
5. Play 버튼을 누르면 빛나는 구슬이 제단 주위를 돌면서 위아래로 움직인다.
6. Game 뷰를 한 번 클릭한 뒤 WASD 또는 방향키로 이동하고, 마우스로 둘러본다. Shift는 달리기, Esc는 마우스 고정 해제다.

사용자가 작업했던 `Assets/S15/S15_Landscape.unity`를 복사해 사용하며 원본은 수정하지 않는다.
따라서 기존 테이블, 화로, 연기, Lava Flow, 조명과 Player 이동 기능이 그대로 유지된다.
독립 장면이 필요한 경우에만 `CG > Mid > Build Standalone Moonlit Altar Scene`을 사용한다.

## 수업 조건과 연결

- 요소 1 - 기하 모델링: `Mid_ProceduralAltar.cs`가 `for`문으로 n각기둥 제단의 정점과 삼각형을 만든다.
- 요소 2 - 변환: `Mid_OrbitingRelic.cs`가 부모를 회전시켜 자식 구슬을 공전시킨다.
- 요소 3 - 추가 변환: `Mid_Spin.cs`가 다이아몬드를 계속 회전시킨다.
- 요소 4 - 추가 변환: `Mid_Bob.cs`가 피라미드를 위아래로 움직인다.
- 이번에 추가한 오브젝트: n각기둥 제단, 빛 구슬, 회전하는 다이아몬드, 위아래로 움직이는 피라미드.
- 재질/조명: URP Lit 재질, Emission 재질, Directional Light와 Point Light를 사용한다.

## 네 요소의 짧은 설명

1. 반복문으로 원 둘레의 아래 정점과 위 정점을 만들고 삼각형으로 연결해 제단을 만들었다.
2. 부모 오브젝트를 회전시키면 자식인 빛 구슬이 제단 주위를 돌게 했다.
3. `transform.Rotate`로 다이아몬드가 계속 회전하게 했다.
4. `Mathf.Sin` 값으로 피라미드의 y 위치를 바꿔 위아래로 움직이게 했다.
